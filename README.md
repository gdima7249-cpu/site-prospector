# site-prospector

Скрипт ищет сайты через Яндекс (или берёт ваш список), находит у них заметные проблемы и готовит черновики писем владельцам.
**Сам он ничего не отправляет:** вы читаете черновики, правите их и одобряете вручную. Отправка — отдельной командой, с лимитом и паузами.


## Самый простой способ: Telegram-бот (Windows)

Пишете боту «стоматология Казань». Бот находит компании этой ниши — **и без сайта, и с сайтом**, — проверяет сайты, расставляет приоритет и для каждой компании подсказывает, что предложить и за сколько. **Письма бот не отправляет**, вы отправляете их сами.

1. Установите Python с [python.org](https://www.python.org/downloads/). В установщике отметьте галочку **Add python.exe to PATH**.
2. В Telegram напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и получите **токен**.
3. Дважды щёлкните `start.bat`. В первый раз он поставит библиотеки и откроет Блокнот: вставьте туда токен, сохраните и закройте.
4. Напишите своему боту `/start`. **Первый, кто написал, становится владельцем**, остальным бот не отвечает.
5. Отправьте нишу и город: `кузовной ремонт Омск`, `натяжные потолки Самара`, `салон красоты Тула`.

### Что показывает бот

```
1. Гараж Петровича · 🚫 нет сайта
   приоритет 85/100: нет сайта, 70 отзывов — активный бизнес
   💰 сайт-визитка по эталону ≈ 24–48 тыс. ₽, поддержка 1000–3000 ₽/мес. Почему: ниша с высоким чеком, город-миллионник, крупный: 70 отзывов
   ✉ тел. +7 (913) 222-33-44
```

**Приоритет (0–100)** — насколько вероятно, что компании нужен сайт и она заплатит:
- сильнее всего — то, что видит сам владелец: нет сайта (+45), сайт не работает (+40), нет мобильной версии, «Не защищено», Flash;
- SEO-мелочи вроде «нет meta description» весят 2–3 балла и в причины не попадают;
- активный бизнес — больше баллов: отзывы (данные 2ГИС), указанные часы работы;
- есть email (+10) или телефон (+5); если связаться нельзя, приоритет не выше 20;
- ниша с высоким чеком (+10) или средним (+5).

**Рекомендация по цене** считается по правилам из `pricing.json`: ниша (чек), город (Москва, Петербург, миллионники, остальные), размер бизнеса (много отзывов) и что нужно — новый сайт или подлатать старый. **Цифры в `pricing.json` — мои стартовые оценки, а не рыночные данные.** Поправьте их под свой город и опыт: файл открывается Блокнотом.

### Команды

- `/draft 3` — черновик письма для компании №3. Для компаний без сайта текст другой, и если email нет, бот подскажет написать в WhatsApp или позвонить.
- `/skip 3` — больше не показывать компанию.
- `/niches` — список ниш, их 55.
- `/addniche натяжные потолки: потолк, натяжн | high` — своя ниша. Слова — части названий компаний, `high`/`mid`/`low` — чек. Свои ниши хранятся в `niches_custom.json`.
- `/sources` — какие источники подключены.

### Источники компаний

| Источник | Ключ | Что даёт |
|---|---|---|
| OpenStreetMap | не нужен, бесплатно | компании с сайтом и без; данные бывают устаревшими |
| Яндекс, API поиска по организациям | нужен | свежие компании, сайт, телефон, часы |
| 2ГИС, Catalog API | нужен | то же плюс **рейтинг и число отзывов** — с ними приоритет точнее |

Ключи кладутся в файл `keys.json` по образцу `keys.example.json`:
```json
{"yandex_org_api_key": "ваш ключ", "dgis_api_key": "ваш ключ"}
```
Оба API, насколько я знаю, платные или с ограниченным бесплатным доступом. Условия, цены и как получить ключ — на сайтах Яндекса (кабинет разработчика) и 2ГИС (платформа для разработчиков). Если ключа нет, бот работает на одной OpenStreetMap. Google не подключён: его API карт требует оплату в Google Cloud.

**Ограничения:**
- Форматы ответов Яндекса и 2ГИС я писал по своему знанию этих API, проверить вживую не мог. Если подключите ключ и бот напишет «Яндекс/2ГИС не ответил», пришлите текст ошибки из чёрного окна.
- Уже проверенные компании бот больше не показывает, каждый поиск даёт новые. Начать заново: удалите `bot_state.json`.

## Что проверяется

Всё пассивно, как обычный посетитель: главная, до двух страниц «Контакты/О нас» и до 15 внутренних ссылок. robots.txt соблюдается.

| Проблема | Вес |
|---|---|
| нет HTTPS / недействительный сертификат | 25 |
| нет мобильной вёрстки (meta viewport) | 20 |
| Flash | 20 |
| низкая оценка Google PageSpeed (только с `--pagespeed`) | 20 |
| главная отвечает дольше 3 с | 15 |
| сертификат истекает меньше чем через 21 день | 10 |
| битые внутренние ссылки | 10 |
| в подвале © двухлетней давности и старше | 10 |
| нет title / mixed content / нет meta description / HTML > 500 КБ / теги font, center, frameset | 5–8 |

Оценка — сумма весов (максимум 100). Чем выше, тем хуже сайт. Уязвимости и версии CMS скрипт **не** ищет: письмо в духе «у вас дыра» читается как угроза.

## Поиск сайтов через API Яндекс Поиска

1. Зарегистрируйтесь в [Yandex Cloud](https://yandex.cloud/), создайте каталог и подключите платёжный аккаунт. Запросы к Search API платные, цены — на странице сервиса.
2. Создайте сервисный аккаунт с ролью для Search API (какую именно — сказано в инструкции) и выпустите для него **API-ключ**. Порядок действий — в [инструкции Яндекса](https://yandex.cloud/ru/docs/search-api/quickstart/v2).
3. Передайте скрипту ключ и ID каталога:
   ```bash
   export YANDEX_SEARCH_API_KEY='ключ' YANDEX_FOLDER_ID='b1g...'
   ```
4. Поиск:
   ```bash
   python prospector.py search "стоматология Казань" "ремонт квартир Казань" --pages 3
   python prospector.py search --queries queries.txt --region 213
   ```
   Найденные домены дописываются в `urls.txt` без повторов. Каталоги и агрегаторы (Avito, 2ГИС, Zoon, ПроДокторов, соцсети, маркетплейсы и т. п.) отбрасываются: у них нет владельца, которому имеет смысл писать. Список — `SKIP_DOMAINS` в `prospector.py`.

Ищите по нише и городу: «стоматология Казань» лучше, чем «плохие сайты». У небольшого локального бизнеса старые сайты встречаются чаще.

> Поля `page` и `region` в запросе я указал по памяти. Документация Яндекса во время разработки была недоступна. Если вторая страница выдачи повторяет первую или регион не учитывается, сверьте имена полей со [справкой по формату запроса](https://yandex.cloud/ru/docs/search-api/operations/web-search-sync) и поправьте функцию `yandex_search`.

## Работа

1. Соберите список сайтов в `urls.txt`, по одному в строке: руками или через Яндекс (см. выше).
2. Проверка:
   ```bash
   python prospector.py audit urls.txt
   ```
   Появятся `out/report.csv` (открывается в Excel), `out/report.json` и `out/drafts/<домен>.txt` — черновики для сайтов с оценкой от 30 и найденным email.
3. **Прочитайте каждый черновик.** Поправьте текст, удалите лишнее. Те, что готовы к отправке, переложите в `out/approved/`.
4. Отправка:
   ```bash
   export SMTP_HOST=smtp.yandex.ru SMTP_PORT=465 SMTP_USER=you@yourdomain.ru SMTP_PASSWORD='пароль приложения' SMTP_FROM_NAME='Имя Фамилия'
   python prospector.py send --dry-run   # сначала посмотреть, что уйдёт
   python prospector.py send             # не больше 20 писем за запуск, пауза 90–135 с
   ```
   Отправленные письма переезжают в `out/sent/` и записываются в `out/sent.csv`. Повторно этим доменам скрипт писать не будет.

Кто попросил больше не писать — добавьте его адрес или домен в `do_not_contact.txt`. Такие сайты не проверяются, и письма им не уходят.

### Полезные флаги `audit`

- `--min-score 40` — порог для черновиков (по умолчанию 30);
- `--pagespeed` — спросить оценку Google PageSpeed (по 10–30 с на сайт). Без ключа Google быстро начинает отвечать «слишком много запросов», бесплатный ключ кладётся в `PSI_API_KEY`;
- `--llm` — письма пишет нейросеть Claude (нужен `ANTHROPIC_API_KEY`, запросы платные). Она получает только найденные проблемы и ваши данные из `sender.json`, и ей запрещено придумывать факты. Всё равно проверяйте текст. Если запрос не удался, скрипт берёт шаблон;
- `--workers 5`, `--check-links 15`.

## Важно до первой рассылки

- **Закон (РФ).** По ст. 18 ФЗ «О рекламе» реклама по email допускается только с согласия получателя. Персональное письмо одной компании про её сайт может не считаться рекламой, но где проходит граница, решают ФАС и суд. С юристом лучше проконсультироваться заранее. Адреса вида `ivan.petrov@...` — персональные данные (152-ФЗ). Поэтому скрипт ставит первыми общие ящики `info@`, `sales@` и т. п.
- **Почта.** Не рассылайте с основного рабочего домена. Настройте SPF, DKIM и DMARC и начинайте с малого объёма.
- В каждом письме есть строка «ответьте «нет», больше писать не буду» и заголовок `List-Unsubscribe`. Отказы выполняйте через `do_not_contact.txt`.
