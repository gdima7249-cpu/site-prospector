# Шаблон «studio» для автоматических демо

Дизайн взят из эталона `kuzovomsk-site/` (сайт Центра кузовного ремонта): тёмный «студийный» стиль, шрифты Inter и Inter Tight, ч/б фото, бегущая строка, фото у курсора в услугах, нижняя панель звонка на телефоне.

`styles.css` скопирован без изменений. Всё, что добавлено для демо, лежит в `css/demo.css` и `js/demo.js`.

## Что бот берёт из эталона, а что нет

Демо собирается для **чужих** компаний, поэтому в нём только найденные о компании факты: название, телефон, адрес, часы, рейтинг и число отзывов. Из эталона **не переносится** ничего, что относится только к Центру кузовного ремонта:
- калькулятор и прайс с их ценами — в демо «уточняйте по телефону»;
- отзывы конкретных людей, скидки, гарантия, оборудование (DOOCAR, Mitra), «с 1999 года»;
- фото цеха со старого kuzovomsk.ru (`svc-geometry`, `svc-bumper`) — это их собственные снимки.

## Фото

Используются только фото со свободными лицензиями (CC BY 2.0 и CC0, Flickr через Openverse), их список — `STUDIO_PHOTOS` в `demo_builder.py`. **Для CC BY автор обязательно указывается**: бот сам добавляет нужные строки в подвал демо («Фотографии на сайте»). Это иллюстрации, а не работы компании, — об этом тоже сказано в подвале.

На настоящем сайте клиента замените их фото его цеха и работ.

## Файлы

```
index.tpl.html   — разметка с подстановками ($name, $phone_text, …), заполняет demo_builder.py
css/styles.css   — стили эталона (без изменений)
css/demo.css     — дополнения: плашка «демо», «уточняйте по телефону», рейтинг, перенос длинных названий
js/demo.js       — скрипт эталона без калькулятора, прайса, отзывов и формы; часы и часовой пояс — из <body data-hours data-tz>
fonts/, img/, favicon.svg
```

При сборке эти файлы копируются один раз в `public_demos/_assets/studio/` и используются всеми демо.
