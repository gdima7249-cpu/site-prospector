# Текст письма клиенту. Строки, начинающиеся с #, — пояснения, в письмо они не попадают.
#
# Бот подставляет вместо слов в фигурных скобках:
#   {компания}  — название компании
#   {моё_имя}   — name из sender.json
#   {проблема}  — один из вариантов ниже, по тому, что нашёл бот
#   {что_ищут}  — что ищут клиенты (например, «автосервис»); если для ниши не задано — «такие услуги»

#   {ссылка}    — ссылка на демо (только в вариантах «демо: ссылка» и «демо: pdf и ссылка»)
#   {подпись}   — signature из sender.json
#
# Править можно всё, кроме строк «=== ... ===»: по ним бот находит части письма.

{демо}

Хорошего дня!
{подпись}
