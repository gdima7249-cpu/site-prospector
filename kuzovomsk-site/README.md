# Сайт «Центра кузовного ремонта» (kuzovomsk.ru)

Одностраничный адаптивный сайт без сборки и зависимостей: HTML + CSS + JS.
Тёмный «студийный» стиль, крупная типографика, ч/б фотографии с единой обработкой.

## Что внутри

```
index.html        — вся страница
css/styles.css    — стили (цвета и шрифты — переменные в начале файла)
js/main.js        — меню, анимации, калькулятор покраски, прайс, отзывы, форма
img/              — фотографии (WebP + JPG), og.jpg — превью для мессенджеров
fonts/            — Inter и Inter Tight (SIL OFL 1.1, файлы лицензий рядом)
favicon.svg, robots.txt, sitemap.xml
```

Разделы: первый экран → бегущая строка → о нас → услуги (фото появляется у курсора) →
технология → **калькулятор покраски** (нажимаете детали на схеме кузова — считается сумма
«от» по прайсу и отправляется в WhatsApp) → прайс по вкладкам → гарантия →
как попасть на ремонт + форма «Оценка по фото» → отзывы (слайдер) → скидки → вопросы →
контакты с картой.

## Контент

Тексты, цены, скидки, ответы на вопросы, отзывы и контакты — со старого сайта kuzovomsk.ru.
Отзывы приведены фрагментами, сокращения отмечены «…».

## Фотографии

- `svc-geometry` и `svc-bumper` — снимки цеха со старого сайта.
- Остальные — фото со свободными лицензиями (Flickr через каталог Openverse): CC BY или CC0.
  **Это не работы сервиса**, а атмосферные иллюстрации. Авторы и лицензии перечислены
  в подвале сайта («Фотографии на сайте») — для CC BY это обязательное условие.
- Все фото приведены к одному виду: ч/б, контраст, виньетка (скрипт обработки описан ниже).

Лучшее, что можно сделать для сайта, — заменить иллюстрации на собственные снимки цеха,
камеры, стапеля и готовых машин (горизонтальные, от 2000 px по длинной стороне).
Достаточно положить новые файлы с теми же именами в `img/`.
